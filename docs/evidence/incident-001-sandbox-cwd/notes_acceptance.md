# 交付物与验收标准 (Acceptance Criteria)

## 交付物 (Deliverable)
- 工作区文件：`primes_sum.py`
- 内容要求：一个可独立运行的 Python 脚本（仅使用标准库），
  计算并打印**前 100 个素数之和**。

## 验收标准 (Acceptance Criteria)

### AC-1 文件存在且可执行
- `primes_sum.py` 存在于工作区根目录。
- 可通过 `python3 primes_sum.py` 直接执行，退出码为 0，无任何报错/异常输出。

### AC-2 输出数值正确
- 脚本打印的数值必须等于前 100 个素数之和 = **24133**。
- 参考依据：前 100 个素数为 2, 3, 5, ..., 541；其和为 24133（已由独立参考脚本验证）。

### AC-3 素数判定逻辑正确
- 判定逻辑不得将 1 视为素数（`is_prime(1) == False`）。
- 判定逻辑必须将 2 视为素数（`is_prime(2) == True`）。
- 判定逻辑对合数返回 False（如 4, 9, 15, 100）。
- 第 100 个素数应为 541，第 1 个素数为 2。

## 验证方式 (Verification Method)
1. 运行 `python3 primes_sum.py`，捕获 stdout 与退出码。
2. 从 stdout 解析出打印的整数，断言其等于 24133。
3. 对脚本中的素数判定函数进行边界测试：1→False，2→True，4→False，9→False，541→True。
4. 断言前 100 个素数列表长度为 100，且末元素为 541。

## 备注
- 关键数字：**24133**（前 100 个素数之和）。
- 后续节点须引用本文件中的 AC-1/AC-2/AC-3 进行验证。
