# 基线定义（Baseline）

> 因工作区为空（无被诊断对象），本基线为**元级基线**：定义“诊断重复失败”类任务的基线口径与锚点规则。

## B1. 基线对象
- 被诊断对象：**缺失**（工作区 0 条目）。
- 因此基线锚点 = 环境事实，而非业务指标。

## B2. 环境基线（本次实测，可复现）
| 项 | 基线值 |
|---|---|
| 工作区条目数 | 0 |
| `.git` 存在 | 否 |
| 松散 git 对象 | 0 |
| 工作区可写 | 是 |
| `subprocess` 可用 | 否（sandbox denied） |
| 工作区外读取 | 否（sandbox denied） |
| 任务输入文件 | 无 |

## B3. 基线判定规则
- 若 `workspace_entry_count == 0` 且 `task_inputs_present == false` → 判定为 **输入缺失基线**，任务进入“元级交付”分支。
- 若存在输入 → 以输入中的失败日志/指标为业务基线（本任务不适用）。

## B4. 基线用途
- 作为“是否可原样重试”的判据：输入缺失基线 ⇒ **禁止原样重试**。
