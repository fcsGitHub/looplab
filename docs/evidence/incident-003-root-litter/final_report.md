## 2. 脚本内容（t2）

```python
def count_primes(limit):
    """Count primes in [1, limit] using the sieve of Eratosthenes."""
    if limit < 2:
        return 0
    sieve = [True] * (limit + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(limit ** 0.5) + 1):
        if sieve[i]:
            for j in range(i * i, limit + 1, i):
                sieve[j] = False
    return sum(sieve)


count = count_primes(5000)
print(count)
```
