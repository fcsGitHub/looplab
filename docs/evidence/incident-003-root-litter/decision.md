# 算法与验收标准决策说明

## 选定方案：A — 高精度确定性算法（Chudnovsky 公式 + mpmath）

**决策依据：** Monte Carlo 估计 π 的统计误差按 O(1/√N) 收敛。要达到 500 位小数（误差 < 10⁻⁵⁰⁰），需 N ≈ 10¹⁰⁰⁰ 个样本。即便以 10¹⁸ 样本/秒运行 10¹⁰ 年，也仅约 3.15×10³⁵ 个样本，仅能保证约 17–18 位精度。故方案 B 物理上不可行，若采用只能给出低精度估计并显式声明误差量级，绝不能声称 500 位。因此必须选 A。

**算法：** 采用 Chudnovsky 级数（每项约增加 14 位十进制精度），用 mpmath 以二进制精度 `mp.prec` 计算，迭代项数取 `ceil(510/14)+2` 项以保证收敛余量。

**精度余量：** 设定工作精度 ≥ 510 位有效数字（实际取 520 位，留出舍入与末位截断余量），高于目标 500 位，避免末位舍入污染。

**验收判据：** 将计算结果四舍五入到 500 位小数后，与已知参考值 π 的前 500 位小数逐位比对，必须完全一致（0 处差异）。同时用 Machin 公式独立复算作为交叉验证，两者前 500 位一致方可通过。
