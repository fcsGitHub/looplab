# 方案说明：用 Python 计算圆周率到 500 位

## 选定方案
**方案 A — 高精度确定性算法**（拒绝方案 B，理由见下）。

## 依赖库
- 主实现：`mpmath` 1.3.0（`mp.dps` 控制十进制有效位；其 `pi` 内部使用 Chudnovsky 级数）。
- 独立交叉校验：标准库 `decimal`（自写 Chudnovsky 公式，`getcontext().prec` 控制精度）。
- 环境已实测：python 3.11.5，mpmath 1.3.0，decimal 1.70 均可用。

## 公式与精度参数
- 公式：Chudnovsky 级数 1/pi = 12 * Σ_{k≥0} (-1)^k (6k)!(13591409+545140134k) / ((3k)!(k!)^3 (640320)^{3k+3/2})。
- 精度设置：计算精度 = **520 位有效数字**（> 510，预留 ≥20 位防舍入/截断误差）。
- 输出：取小数点后 **恰好 500 位**（截断而非四舍五入，避免第 501 位污染）。

## 验收判据
1. 输出字符串形如 `3.` + 500 位数字，小数点后长度 **恰好 500**。
2. 与参考值（mpmath 520dps 输出）**逐位一致**，前 500 位全等。
3. 交叉校验：`decimal` 自写 Chudnovsky 与 mpmath 结果前 500 位全等（已实测通过）。
4. 首 50 位须为 `14159265358979323846264338327950288419716939937510`。

## 为何拒绝方案 B（Monte Carlo）
- 估计量 pi_hat = 4*p_hat，p=pi/4；标准差 σ = 4*sqrt(p(1-p)/N)。
- log10(σ) = 0.2154 - 0.5*log10(N)。要 σ≈1e-500 需 **log10(N)≈1000.4**，即 N≈10^1000 次采样，物理不可行。
- 即使 N=10^10 也仅 σ≈1e-4.78（约 4-5 位），95% 置信区间半宽 ≈1e-4.49。
- 结论：Monte Carlo 只能给低精度估计（约 3-6 位）并附置信区间，**不能声称达到 500 位**。
