# LoopLab 工作台 · 前端设计 v2

> 面向《自我改进 Agent 框架设计》第 16 节的前端设计实施，v2 迭代。
> 设计样机（prototype）：纯 HTML/CSS/JS，无构建步骤；演示数据为 **界面示意 fixture**，字段形状与 [`api-contract.md`](./api-contract.md) 一致，接入真实控制服务后由 SSE 事件流驱动。
> 视觉参考 Kimi Code Desktop / Codex 桌面端：暗色优先、近单色、单一绿色强调、CLI 式状态栏。

## 运行

```bash
python -m http.server 8321 --directory front-design   # 打开 http://localhost:8321/index.html
```

直接双击 `index.html` 亦可（零依赖）。

## v2 布局：Agent 区（大篇幅）+ 极简工作区

```text
┌────────────────────────────────────────────────────────────┐
│ 顶栏：目标 · 状态 · 暂停/取消 · 连接 · 主题 · 设置           │
├─────────┬──────────────────────────┬───────────────────────┤
│ 项目     │  Agent 区                 │  工作区（极简）         │
│ 会话     │  ┌ 主 Agent 摘要卡 ──┐    │  当前工作 / 轨迹        │
│         │  │ 目标·正在·下一步    │    │  演进与版本 / 证据资产   │
│         │  │ 计划 ●─●─◐─○─○ 3/5 │    │                       │
│         │  └ 点开 → 检查器详情 ┘    │                       │
│         │  子 Agent 行（点开执行）   │                       │
│         │  对话流（滚动）            │                       │
│         │  ▍任务状态栏 ⌄（展开任务） │                       │
│         │  输入 + 快捷干预           │                       │
└─────────┴──────────────────────────┴───────────────────────┘
                        ⇧ 检查器按需滑出（Esc 关闭）
```

### Agent 区（占据主要篇幅）

- **主 Agent 摘要卡**：角色、目标、正在做、下一步、计划进度轨（done/run/todo 节点），整卡点击进入检查器查看完整计划、冻结上下文、预算分账、检查点。
- **子 Agent 列表**：每行 = 角色徽标 + 任务 + 状态（运行中/等待/已暂停/完成/失败）+ 耗时，点击进入检查器查看**执行步骤时间线**（工具调用、检查点、进行中的脉冲节点）与产物引用。角色按需启动，非常驻聊天。
- **对话流**：用户消息 / Agent 消息（可嵌紧凑数据卡），运行中显示 typing 活动行。
- **任务状态栏**：CLI 风格单行（mono）——状态 · 任务进度 · 运行中任务 · 预算；点击或按 `T` 展开任务列表（含角色与等待原因），点任务进检查器。
- **输入区**：steer 指令（不打断当前工具）+ 快捷干预 chips。

### 工作区（尽可能简洁）

无卡片盒，细分隔行 + 小字眉题：

| 视图 | 内容 |
|---|---|
| 当前工作 | 正在做/版本/进展/等待原因/下一步 + 核验进度（仅固定批次如 3/8，开放研究不显示假百分比）+ 剩余额度 |
| 轨迹 | 运行/attempt 列表（状态点、成本），点击行内展开 mono 事件日志与游标续传标注 |
| 演进与版本 | 紧凑候选行（digest/标题/父版本/状态），点开看测试缺口与回滚方式；已发布/灰度/证据不足/拒绝/回滚色彩语义区分 |
| 证据与资产 | Artifact（digest/producer）/ Claim（立场+范围）/ 技能候选 / 假设卡，点开看详情 |

## 设计令牌

| 令牌 | 暗色（默认） | 浅色 |
|---|---|---|
| bg0–bg3 | `#0d1013 → #1d232a` | `#f5f6f4 → #eff1ed` |
| accent | `#3ecf8e` | `#12805f` |
| warn / danger | `#d9a03f` / `#e06c5f` | 同 |
| text1/2/3 | `#dde1e6 / #98a2ab / #5f6a73` | `#1f2420 / #57615a / #8a938b` |

- 默认跟随系统（`color-scheme` + `light-dark()` 回退），顶栏可切换并持久化。
- 状态永远文字 + 色彩双重编码；等宽字体用于 ID/事件/预算；细边框无重阴影。

## 已实现的关键状态

运行 / 用户暂停（排空语义，accepted→applied 两段）/ 等待预算（不空转）/ 已取消（确认对话框列副作用）/ 断线重连（`after=cursor` 游标恢复、事件去重）/ 审批待办 / 空态（新会话、空轨迹、空证据）/ 负结果（证据不足、条件内否定、已回滚）。

## 键盘

`Enter` 发送 · `Shift+Enter` 换行 · `1–4` 切换视图 · `T` 任务状态栏 · `P` 暂停/恢复 · `N` 新建会话 · `?` 帮助 · `Esc` 关闭检查器/弹层。Tab 面板遵循 ARIA tab 模式。
